# MiniProjeto_CasaDigital

Projeto realizado junto ao Instituto Consuelo com o intuito de **aprender e me desenvolver como profissional de tecnologia**.
Este projeto foca no **gerenciamento de cursos, alunos, instrutores e progresso de aulas**, utilizando **Python** e **PostgreSQL**.

## Estrutura do Projeto
MiniProjeto_CasaDigital/  
├─ python/ ->scripts python  
├─ sql/ -> scripts sql  
│ ├─ schema.sql # Estrutura do banco  
│ └─ dados.sql # Dados gerados pelo script Python  
├─ venv/ # Virtualenv(gerada a partir do makefile)  
├─ requirements.txt # Dependências do projeto  
└─ docs/  
│   └─ documentacao.md # Documentação detalhada do projeto
